# eSIM Provisioning Guide

eSIM profiles are delivered through a QR code or the self-service app.

## Steps

1. Verify the customer's identity with strong identification.
2. Confirm the device supports eSIM.
3. Generate a single-use activation code in the provisioning portal. Codes expire after 7 days.
4. The customer scans the QR code. The previous physical SIM is deactivated when the eSIM registers on the network.

## Common errors

- **Profile already installed** — the code was used once. Generate a new code.
- **Device not supported** — the device is locked to another operator or does not support eSIM.

eSIM profiles of type ESIM-5G support 5G standalone.
