# 5G Home Internet Setup

5G Home Internet (FWA-5G-HOME) uses an indoor 5G gateway.

1. Place the gateway near a window facing the nearest base station. The coverage map shows the direction.
2. Signal quality RSRP better than -100 dBm is recommended.
3. If speeds are below 50 Mbit/s, try a different position or order an outdoor antenna.

Check for active incidents affecting 5G in the customer's area before booking a technician.
